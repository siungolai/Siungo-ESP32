# rlcd-workbench

**ESP32-S3-RLCD-4.2 单屏多面板桌面工作台**。一块 4.2 寸全反射黑白屏 + 两枚板载按键，做一个放在桌上的常驻工作台：左栏是超大号时间、宠物插件位置与温湿度，右栏是公历月历与待办，另一个面板看自家服务器的健康状况；AI 对话面板本期不做。

## 它长什么样

```
┌────────────────────────────────────────────────┐ 400 px
│ 10月22日周四                  待办6 ▮ wifi │  ← 页首（常驻；时间在面板一隐藏）
├────────────────────────────────────────────────┤
│      10:22      │ 一 二 三 四 五 六 日      │
│      (62px)     │ ┌──┬──┬──┬──┬──┬──┬──┐   │
│        31       │ │12│13│14│15│16│17│18│   │  ← 面板一（本地）
│    (20px 居中)  │ ├──┼──┼──┼──┼──┼──┼──┤   │    两栏等宽各 200 px
│ ┌──────┐        │ │19│20│21│22│23│24│25│   │    月历是三行滚动窗口
│ │ 宠物 │        │ ├──┼──┼──┼──┼──┼──┼──┤   │    今天（22）恒在中间行
│ │ 插件 │        │ │26│27│28│29│30│31│ 1│   │
│ └──────┘ 24.5°C │ └──┴──┴──┴──┴──┴──┴──┘   │
│            48%  │ □ 交周报        2h       │
│                 │ □ 买牛奶        明天     │
│                 │ □ 缴费          逾期     │
│                 │ □ 换滤芯        3天      │
│                 │ □ 取快递        今天     │
│                 │ □ 整理照片     10-28     │
├────────────────────────────────────────────────┤
│ 本地                              同步中      │  ← 页尾（常驻）
└────────────────────────────────────────────────┘ 300 px
```

左栏是**大号 `HH:MM`（`logisoso62`，实测 179 px，撑满 192 px 内宽）+ 秒 `SS`（`logisoso20`，大小不变、单独一行居中）**；下方左边是**宠物插件虚线占位框**（本期不画宠物）、右边是**右对齐的温湿度**（只有数字和单位：`24.5°C` / `48%`）。日期与星期只在页首出现一次，**页首中间的时间在面板一隐藏**（面板一已经有大钟）。右栏是**三行滚动月历**（上周 / 本周 / 下周，今天恒落中间行）+ **6 行待办**；**月历格内底部有 1–3 个计数点**，表示这天有几条行程（超过 3 条饱和成 3 个点）；**非本月日期只画数字、不画外框**（例如行 2 末尾的 `11/01`）——框代表「这一格属于本月网格」，没有框就是「这天不在这儿」。月历只画三行是刻意的：整月最少要 4 行、放不全，而把整月压进三行就得把数字缩到 10 px（1bpp 下不可读）。省下的空间给了待办——6 行，正好对齐待办契约的 6 个槽位。

另一个面板：**服务器**（自家服务器上四类资源 + 六个服务探针 + 证书剩余天数）。原定的第三个面板（AI 对话）**本期连设计也不做**——不占面板位、不做占位页。

## 两个面板

| 面板 | 内容 | 数据来源 |
|---|---|---|
| **本地** | 大号时间 + 小字秒 / 宠物（一只鹅）/ 温湿度（无中文标签）/ 三行滚动月历（带行程计数点）/ 最近 6 条待办 | 本板 SHTC3 + PCF85063 RTC + 服务器待办与行程 |
| **服务器** | CPU / 内存（MB 明细）/ 磁盘（GB 明细）/ 负载 + 6 个服务探活（`www` / `select` / `wb` / `api/photos` / `api/health` / `ma12` 出站 TCP）+ 证书天数（11 项一页） | 复用 `status-oled3` 的 `/status/snapshot.json`，契约扩到 22 字段 |

**声音不占面板位**：它没有独立的页面，只在**整点**从喇叭里响一声（约 340 ms 的两声「嘀嘀」），以及**在设置版面切档时**当作按键反馈响一遍。响不响由设置版面那四行决定（见下节），默认每天 08:00–21:00 每小时一次。

**两枚按键，六个手势槽，全部有归属**。手势的语义随位置变化（关于页有两个版本）：

| 位置 | KEY 短按 | KEY 长按 | KEY 双击 | BOOT 短按 | BOOT 长按 | BOOT 双击 |
|---|---|---|---|---|---|---|
| 面板一 / 二 | 下一个面板 | 回主页 + 清理状态 | 关于页 | 立即拉数据 + 重绘 | 对比度 5 档循环 | *预留，不绑定* |
| 关于页·教程版面 | 退出关于页 | 回主页 + 清理状态 | 关于页默认视图 | **进设置版面** | **进设置版面** | *预留，不绑定* |
| 关于页·设置版面 | 退出关于页 | 回主页 + 清理状态 | **回教程版面** | **选中行下一行（循环）** | **切换选中行选项（声音相关行当场试听）** | *预留，不绑定* |

**关于页 = 上半设备信息固定 + 下半互斥两版**（教程版面 / 设置版面），设置版面不是一张独立的页、也不是浮层。**v0.1.1 只有一项**：屏幕对比度，5 档 `{40, 50, 60, 70, 80}`、默认第 3 档 60。**v0.1.5 起共五项**：

| 顺序 | 项 | 选项 | 默认 |
|---|---|---|---|
| 1 | 对比度 | 5 档 `{40, 50, 60, 70, 80}` | 第 3 档（60） |
| 2 | 声音 | `开` / `关` | 开 |
| 3 | 音量 | 5 档，显示 `4/5 (85)` | 第 4 档（85） |
| 4 | 整点报时 | `开` / `关` | 开 |
| 5 | 夜间静音 | `开` / `关` | 开 |

全部**跨重启保留**（NVS，变更即写，namespace `rlcd`）。**显示仍只占 4 行**（`y = 178/196/214/232`），第 5 项出现后选中行滚出可见区才整窗上滚一行，右上角位置指示 `1-4/5` → `2-5/5`；截断上限 `y > 240` 是版面的硬边界，所以**「设置」标题行与两行键位说明始终不动**，动的只有中间四行。教程版面里 BOOT 长按也绑成「进设置版面」是刻意的——旧习惯「BOOT 长按调对比度」两拍之内仍然有效（长按一次进设置版面，再长按一次切到对比度）。

**「声音」是总闸**：关掉它整点不再响，但音量 / 整点报时 / 夜间静音三行**照样能切**（不画灰、不禁用）——否则用户想先调好音量再开总闸就没路了。总闸真的挡下一次报时时，串口会留一行 `skipped, master=off`，**而不是悄悄不响**；四条判定的每一次跳过都有对应日志（`master=off` / `time unreliable` / `quiet hours` / `chime=off`），这是这条链路唯一的可观测面。**切「声音」「音量」「整点报时」「夜间静音」四项中的任一格都当场响一遍提示音**，这是按键反馈，**不受总闸约束**（总闸管的是整点提示音，不是按键反馈）。

> ⚠️ **「夜间静音」是正向语义**（开 = 夜里真的静音），与用户原话「夜间报时」字面相反。这是 grilling 里明确选的：`夜间_` 那个下划线是一个「不」字。三项统一用 `开`/`关`，不做语义反转的特殊显示。**将来对着原始需求找「夜间报时」按钮的人会找不到它 —— 它叫「夜间静音」。**

## 这块板值得知道的几件事

- **屏幕是横屏 400×300**，官方文档写的「300×400」是物理尺寸。官方 u8g2 封装默认 `U8G2_R0`，**必须显式传 `U8G2_R1`**。
- **官方 u8g2 驱动的 gamma 与官方例程不一样**（C1 / C4 / D8 / B2 四组）——抄错就发灰、反差不对。**以官方例程的 `ST7305_U8g2` 为准**。
- **官方封装的命令通道是空的**：`sendF("c", 0x39)` 一定失败，esp-idf 端口更会不拉 DC 低把 `0x39` 当数据写进显存。**模式命令与对比度必须绕过 u8g2 的 CAD 层自己发**。
- **本屏无背光**，暗处不可见。本项目**不熄屏**（只切 LPM），因为熄屏在无背光屏上等于「看起来坏了」。
- **PWR 是纯电源开关**，没有可读电平，不能当第三个按键。
- **触摸控制器型号官方未公布**，不能作方案基石。
- **CHG / WRN 灯没有 GPIO 可读**，所以不画充电图标。
- **电池是 1/3 分压采样**（GPIO4），电量公式抄官方 `03_ADC_Test`。
- **ESP32 newlib 没有 zoneinfo**，`configTzTime("Asia/Shanghai")` 不生效 → 本项目内置 IANA → 偏移对照表。
- **音频这条路上有三个"日志全绿但没声音"的坑**（v0.1.5 各踩一次，全写进 ADR-0022）：
  - `esp_codec_dev_write()` 返回成功**只代表数据进了 DMA 队列**，不代表出了声。它照样会在静音状态下返回成功。
  - `es8311_suspend()` 会把 DAC 音量寄存器清成静音值，而 `esp_codec_dev_open()` **每次都先 suspend 再 start** —— 所以音量必须在**每次 open 之后**重写，不是"开机设一次"。
  - 提示音太短会被**开流关流的固定开销整段吞没**：150 ms 只响第一声，340 ms 才稳。
- **`src/` 下的 `ESP_LOGI` / `ESP_LOGE` 一条都不会输出**：`esp32-hal-log.h:32-34` 把 `CONFIG_ARDUHAL_LOG_DEFAULT_LEVEL` 定成 `ARDUHAL_LOG_LEVEL_NONE`，而 `lib/` 里的普通 C 组件（如 `esp_codec_dev`）走 IDF 的 esp_log 反而有输出。**排障一律用 `Serial.printf`**，否则会误判成"这段代码根本没执行"（这个假象浪费过两版烧板）。

## 本期明确不做

**语音录制、播放音频文件、与服务器 AI 通讯** —— 这三条是原始需求里的，**有意延期**，不是遗漏。技术路线写在 `ADR-0011`（设备侧 ES8311 + ES7210 + `esp_codec_dev` 本地库、服务器侧需要从零起 WebSocket + ASR/TTS、国内 API 直连可行但海外 443 出网被封）。

> 📌 **v0.1.5 的边界修正**：`ADR-0011` 原本把「声音播放」整块延期，**v0.1.5 只把其中一小块拿了出来** —— 本地合成提示音（整点报时的「嘀嘀」）。它不读文件、不连网、不涉及编解码，只是往 DAC 推一段方波。**录制、播放音频文件、语音 AI 通路三条仍然全部延期**，ADR-0011 的路线与五条前置事实一条没变。判据：**要「内容」的才算声音播放，只要「响一声」的不算。** 切分记在 `GLOSSARY.md` 的「提示音（chime）」与「语音链路（仍延期）」两个词条，决策见 `ADR-0022`。

其余不做项（AI 对话面板、触摸、农历、设备端编辑待办、SD 卡缓存、OTA、充电图标、蜂鸣器、信号强度、夏令时、外壳）见 `策划案.md` §9。

## 硬件

- **目标板**：Waveshare **ESP32-S3-RLCD-4.2**（4.2 寸 400×300 全反射 1bpp 屏、ESP32-S3-WROOM-1-N16R8、8MB OPI PSRAM、板载 BOOT / KEY 两键、SHTC3 温湿度、PCF85063 RTC、电池电量采样、ES8311 + ES7210 音频链路 + NS4150B 功放）
- **不用外接任何器件**（喇叭除外）：两键、传感器、RTC 全在板上。**本板无蜂鸣器** —— 提示音走的是 ES8311 + 功放 + 外接喇叭那条路，和蜂鸣器完全是两回事。
- **v0.1.5 起用**：**MX1.25 外接口的 8 Ω 2 W 喇叭**（随板附送），本地合成提示音用
- **仍不用**：麦克风（录制延期，ES7210 已初始化但 `kAddrEs7210` 不参与）、SD 卡（不做缓存）、触摸
- **排母（2×8）全空置**，留给将来的扩展

## 技术栈

- **Arduino-ESP32 + PlatformIO**，**只在本项目锁** `espressif32@~8.0.0`（Arduino-ESP32 3.3.12 / IDF 5.5.5）——仓库其余 9 个工程不动
- **u8g2**（v2.36.18）+ 官方 `ST7305_U8g2` 骨架，自建封装补命令通道
- **`lib/esp_codec_dev`**（本地库，v0.1.5 起）：ES8311 驱动 + I2S 数据面。**registry 上 404，只能以本地库纳入**（`library.json` 手写，`srcFilter` 只留 ES8311 与必要 platform 文件，裁掉 ESP7210 / TDM / SPI 分支省 Flash）。配套 `platform/audio_codec_ctrl_i2c.c` 走 IDF 新驱动，控制句柄由 `i2cbus::busHandle()` 暴露
- **单线程 `loop()`**，不需要 FreeRTOS 任务与互斥锁
- HTTP 用 Arduino `HTTPClient`，JSON 用手写扁平取值器（复用 `status-oled3/src/jsonfield.cpp`）
