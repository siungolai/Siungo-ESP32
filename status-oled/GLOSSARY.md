# status-oled 术语表

本项目独有的术语。仓库级硬件事实（板卡、GPIO、SSD1306 协议、资源口径）
一律以 HARDWARE.md 为准，不在这里重复。

| 术语 | 含义 | _Avoid_ |
|---|---|---|
| 页（page） | SSD1306 显存的 8 行像素 × 128 列，一个"页"就是屏幕上的一个完整画面。本项目共 4 页，由按钮循环切换。 | 页面 / 界面 / 屏 |
| 页眉 | 每页第 0 行，格式 `P1/4 OVERVIEW`：当前页 / 总页数 / 页名。 | 标题栏 / 状态栏 |
| 署名 | 第 7 页（屏幕最底部 8 像素）右对齐的 `SIUNGOLAI`，四页都画。用普通 5x7 字模，起点 `LOGO_X=74`。 | logo / 水印 / 版权 |
| 翻页 | 短按按钮切到下一页，第 4 页再按回第 1 页。不自动轮播、无闲置回首页、无长按翻页。 | 切屏 / 换页 / 翻屏 |
| 总览页 | P1，取消自动轮播后第一屏必须是信息量最大、最能回答"现在怎么样"的那一页。 | 主页 / 首页 / 仪表盘 |
| BOOT / RST 计数 | 两个 RTC 计数器：`BOOT` 数全部上电，`RST` 只数非 POWERON 复位。 | 启动次数 / 重启次数 |
| 复位原因 | `esp_reset_reason()` 的返回值，11 种枚举；屏上用 `resetReasonName()` 映射成短名，最长 11 字符（`DEEP SLEEP` / `SW RESTART`）。 | 错误码 / 故障类型 |
| magic 校验 | 上电时比对 RTC 里的 `0x53544131`（"STA1"），不匹配就把 BOOT/RST 计数清零。用来区分"RTC 里的垃圾值"和"有效计数"。 | 校验和 / 签名 |
| 总线扫描 | 依次对 0x08..0x77 发起 `endTransmission`，记录所有有应答的地址。启动时做一次，之后每 10 秒静默重扫。 | 设备发现 / 探测 |
| 静默重扫 | 每 10 秒重扫一次总线，只更新 P4 的数据，不触发重绘。 | 后台扫描 / 定时扫描 |
| 距上次扫描 | P4 的 `LAST n s ago`，从上一次扫描完成起算的秒数，到 10 秒归零重算。 | 扫描间隔 / 刷新周期 |
| 上电即显 | 开机后不跑字模自检、不等按键，直接渲染第一页。自检是诊断动作，只在按住按钮 ≥1.5s 时发生。 | 即时显示 / 秒开 |
| 字模方向自检 | 画两条相隔 14 行的 1x4 竖条，停 6 秒。判读"哪条离屏幕垂直中心更远"，不依赖任何字模，所以检查本身不会跟着一起反。 | 字库检测 / 显示自检 |
| 地址回退 | `begin()` 先探主地址 `0x3C`，无应答再试 `0x3D`（少数模块出厂是 0x3D）。 | 备选地址 / 地址切换 |
| 软件消抖 | 用 `millis()` 状态机过滤按键抖动：读到低电平后等 30ms，仍为低才认定按下。不用 `delay()`，不阻塞主循环。 | 延时消抖 / 硬件消抖 |
| 标签列 / 数值列 | 每行左侧的标签顶列 0（左对齐），数值右对齐贴列 20；数值起始列 = 21 − 数值长度。 | 左栏 / 右栏 |
| 右对齐例外 | `MAC` 行是全屏唯一不右对齐的行：它的数值 17 字符，右对齐会让起始列 = 4 与标签粘连。该行改用 `drawRowLeft()`，数值从第 5 列起。 | 特殊行 / 破例行 |
| 生效地址 / 普查地址 | P4 的 `ADDR` 是驱动**正在对话**的那个从机（随地址回退变化，来自 `display.address()`）；`SCAN` 是**全总线普查**结果（来自总线扫描，与驱动无关）。单屏场景两者应一致。 | 本地地址 / 设备地址 |
| 固件占用率 | P2 的 `FLASH nK/mK p%` = `ESP.getSketchSize()` / app0 分区大小。**分母不是芯片的 16MB Flash**，程序只能装进 app 分区。 | Flash 使用率 / 硬盘占用 |
| 碎片率（FRAG） | P3 的 `FRAG n%` = `(DRAM − MAX) / DRAM`。衡量"可用堆里最大连续块之外的部分"占比，越高越碎。 | 内存碎片 / 碎片化程度 |
| RTC 慢速内存 | ESP32-S3 上复位后仍保持供电的 16KB 内存区，地址 `0x50000000` 起。`RTC_NOINIT_ATTR` 变量落在这里的 `.rtc_noinit` 段。 | 备份内存 / RTC 内存 |

## 命名约定

- 首次出现的缩写给全称：I2C（Inter-Integrated Circuit）、PSRAM
  （Pseudo Static RAM）、MAC（Media Access Control）、SDK（Software
  Development Kit）、ADC/DAC/GPIO 等。
- 引用硬件事实带 HARDWARE.md 的 §节号锚点，不用行号（行号易腐化）。
- 引用决策带 ADR 编号，格式 `ADR-NNNN`。
- 串口日志一律 ASCII：中文 UTF-8 到部分串口工具会变乱码。
